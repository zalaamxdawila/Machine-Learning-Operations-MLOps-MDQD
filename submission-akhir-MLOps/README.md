| Masalah                 | Customer Personality Prediction adalah masalah klasifikasi yang bertujuan untuk memahami perilaku pelanggan berdasarkan data demografis, kebiasaan belanja, dan interaksi dengan produk. Analisis data yang tepat dari berbagai faktor ini dapat membantu dalam: mengidentifikasi segmen pelanggan, meningkatkan strategi pemasaran, dan memprediksi kecenderungan pembelian pelanggan.                                                                                                                                                                  |
| Solusi machine learning | Machine learning dapat menjadi salah satu solusi untuk mengatasi masalah klasifikasi pelanggan ini. Dengan menggunakan algoritma machine learning, model prediksi dapat dikembangkan untuk mengelompokkan pelanggan berdasarkan berbagai faktor yang tersedia dalam dataset.                                                                                                                                                                                                                                                                             |
| Metode pengolahan       | Dataset dibagi menjadi data training dan evaluation dengan rasio 8:2. Dataset yang digunakan pada proyek ini terdiri dari dua tipe data, yaitu data kategorikal dan numerikal. Metode pengolahan untuk data kategorikal adalah mengubahnya menjadi bentuk one-hot encoding, sedangkan untuk data numerikal dilakukan normalisasi ke dalam range 0-1.                                                                                                                                                                                                     |
| Arsitektur model        | Arsitektur Model ini dibangun dengan pendekatan deep learning yang secara optimal menggabungkan fitur kategorikal dan numerikal melalui lapisan concatenate. Arsitektur jaringan terdiri dari tiga lapisan Dense berturut-turut dengan 256, 64, dan 16 neuron, masing-masing menggunakan aktivasi ReLU untuk menangkap pola kompleks dalam data. Lapisan terakhir adalah lapisan output dengan satu neuron yang menggunakan aktivasi sigmoid, yang berfungsi untuk mengklasifikasikan data dalam bentuk probabilitas biner. Model ini dikompilasi dengan optimizer Adam menggunakan learning rate 0.001 dan loss function binary crossentropy, memastikan proses pembelajaran yang stabil dan konvergen. Evaluasi model dilakukan dengan metrik Binary Accuracy untuk menilai seberapa baik model dalam mengklasifikasikan data secara akurat.                                                                                                                                                                                                                                      |
| Metrik evaluasi         | Metrik evaluasi yang digunakan yaitu ExampleCount, AUC, FalsePositives, TruePositives, FalseNegatives, TrueNegatives, dan BinaryAccuracy.                                                                                                                                                                                                                                                                                                                                                                                                                |
| Performa model          | Berdasarkan nilai metrik yang dihasilkan dari Evaluator, diperoleh nilai keseluruhan AUC sebesar 85.4%, Binary Accuracy sebesar 98.2%, FN, FP, TN, TP masing-masing 320, 180, 850, dan 237 dari 1587 Example Count. Pada pengujian model dengan tf-serving juga dapat memprediksi label yang sesuai dengan ground truth. Hasil metrik menunjukkan performa yang kurang baik, namun sudah cukup. Performa model masih dapat ditingkatkan lagi melalui proses preprocessing yang lebih mendalam, seperti mengatasi missing values, membuang outliers, dll. |
| Opsi deployment         | Proyek machine learning ini dideploy menggunakan salah satu platform as a service (PaaS) yaitu Railway yang menyediakan layanan gratis untuk mendeploy sebuah proyek.                                                                                                                                                                                                                                                                                                                                                                                    |
